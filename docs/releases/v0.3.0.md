# LiPlayer 0.3.0

Rebrands the application to **LiPlayer** with bespoke macOS icons/logo assets, completes a full codebase & UX audit pass, switches `libmpv` integration from polling to event-driven wakeups, and establishes complete GPLv3 attribution and open-source community documentation under `aliahadmd/LiPlayer`.

## Downloads and sources

Download **LiPlayer-0.3.0-macOS-arm64.zip**, unzip it, and move `LiPlayer.app` into Applications. Requires **Apple Silicon and macOS 27.2 or later**. Existing `~/Library/Application Support/VideoPlayer` data migrates automatically to `~/Library/Application Support/LiPlayer` on first launch, and legacy `.vpqueue` files remain readable alongside `.lpqueue`. This build is **ad hoc signed and unnotarized**; macOS may block a downloaded copy.

The matching application source is **LiPlayer-0.3.0-source.tar.gz**. Native dependencies are unchanged from v0.1.0. Their full sources are in the shared [third-party source archive](https://github.com/aliahadmd/LiPlayer/releases/download/v0.1.0/VideoPlayer-0.1.0-third-party-sources.tar.gz), SHA-256 `fdad2bd2d76001ad94ab7b3a464c908a0fb7b160a329e8f30f35a84ed22bef73`. Download both source archives for the application and its dependencies. `LiPlayer-0.3.0-dependency-sources.json` records this same link and hash.

## Highlights

- **LiPlayer brand & icons:** New obsidian-glass `AppIcon.icns`, `.lpqueue` document icon (`LiPlayerQueue.icns`), in-app logo mark, `.lpqueue` + `.vpqueue` support, and automatic `VideoPlayer` → `LiPlayer` Application Support migration.
- **Engine & lifecycle reliability:**
  - Replaced the 100ms idle polling timer with event-driven `mpv_set_wakeup_callback` delivery, cutting command/seek latency and eliminating idle wakeups.
  - Hardened `GLRenderer` `CGLContextObj` retention/release and clean teardown, checked `mpv_set_option_string` return codes, read runtime `mpv-version` dynamically, and added a 4-second shutdown watchdog so `⌘Q` cannot hang on stalled streams.
  - Fixed `startupResumeTarget` so non-zero initial PTS, keyframe seek offsets, or disabled resume can never lock out history/workspace checkpoint saving.
  - Fixed Repeat mode (`Current file` / `Queue`) when `autoNext` is off while preserving file adjustments when repeating the same item.
  - Fixed macOS Now Playing / media-key `Play`/`Pause` recovery and added Control Center scrubbing (`changePlaybackPositionCommand`).
- **UI/UX, shortcuts & library polish:**
  - Debounced single-click pause against double-click full screen so double-clicking no longer pauses playback.
  - Fixed `video-aspect-override` to use mpv's `"no"` (`-2.0`) default, fixed speed rounding + dynamic Inspector speed picker tags + `0.25×` Transport preset, eliminated scrubber snap-back stutter, added ephemeral playback HUD feedback, dynamic fullscreen notch safe-area padding, drag-and-drop highlight overlay, and auto-dismissing notices.
  - Added Library & Queue filtering, Queue drag-to-reorder and Clear Queue, distinguishable network URL titles, per-slider reset buttons, debounced Settings font editing, history-wipe confirmation, unified branded Settings/About window, and focus-safe keyboard handling.
  - Synced all supported media/subtitle/playlist extensions in `Info.plist`, added `NSOpenPanel` file filters, fixed `.m3u` colon filenames & bounded file-size prechecks, fixed `FolderLibrary.relink` symlink normalization and `.app` package exclusion, and hardened packaging/verification scripts.

## Verification

Passed **34 model tests** (`swift test`), **35 cross-process persistence checks** (`scripts/verify-workspace.py`), and **81 real playback checks** (`scripts/verify.py`) against the signed `LiPlayer.app` release bundle (50 bundled native libraries, zero Homebrew runtime dependencies).

Apple Silicon/macOS 27.2+, OpenGL SDR presentation, HDR-to-SDR tone mapping, and ad hoc unnotarized signing remain the current release boundaries.
